# Sample audio

- `0.wav`, `1.wav`: LibriSpeech test clips (CC BY 4.0), as shipped with the k2-fsa model.
- `l2arctic-ska-a0049.wav`: L2-ARCTIC speaker SKA, sentence arctic_a0049, "Gregson was asleep when he reentered the cabin",
  with 0.66 s of silence in front. This is the website's "Try a sample" clip.
- `l2arctic-ska-a0010.wav`: L2-ARCTIC speaker SKA (Arabic L1), sentence arctic_a0010, "I'm playing a single hand in
  what looks like a losing game", with 0.66 s of silence added in front. L2-ARCTIC is © Texas A&M University, CC BY-NC 4.0
  (Zhao et al., Interspeech 2018). Used here for non-commercial demonstration.
